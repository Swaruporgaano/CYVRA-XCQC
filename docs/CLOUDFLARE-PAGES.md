# Cloudflare Pages — deprecated

> **Use Workers + Wrangler instead.** See [`CLOUDFLARE-WORKERS.md`](./CLOUDFLARE-WORKERS.md).

This repo previously documented **Cloudflare Pages** (Git build + static output directory). Hosting is now **Cloudflare Workers** with static assets via `apps/web/wrangler.jsonc` and `npx wrangler deploy`.

Netlify remains deprecated. Render API and Neon are unchanged.
